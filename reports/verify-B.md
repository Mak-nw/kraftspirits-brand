## 8. Позитивні контролі

1. Градієнт, доданий у копію сторінки (`.hero--lp::before`), метрика «чисте фото» → різниця 23.32 (чисто ≈1.0): метрика ловить оверлей.
2. Білий H1 на світлому небі (екскурсії) → піксельний контраст 2.0:1, 100% пікселів <3:1: метод ловить низький контраст; ним же знайдено реальні 1.07:1 у бочок і 1.04:1 в «Ціні» екскурсій.
3. Дані шаблону +1 символ / неіснуюча іконка / файл / тема / якір → збірка падає з поясненням (7 мутацій, розділ 7).
4. Контроль «0 порушень» `check-ds` D8: на реальних дефектах розділу 2 `check-ds` = 0 — отже D8 НЕ є надійним контролем для тексту на змішаному фоні (це знахідка, не підтвердження).

## 12. Не перевірено

Safari/Firefox, тач, реальний hover/focus-кільця мишею (лише синтетичні події й `qa:states`), контраст при увімкненому паралаксі (`parallax=soft`: кадр зсувається на кілька px), живий GitHub Pages і `BASE_PATH` на мережі, `dpr 2` для геометрії (піксельні заміри — dpr 2; геометрія — dpr 1), скрінрідери/клавіатурний прохід лайтбокса, мобільні/планшетні ширини (за правилами проєкту не верстаються), Opus-варіант 77dd7d09 проти макета замовника (макета нема), відповідність копірайту «за змістом» поза рядковим збігом. Процес: scratchpad спільний з іншими агентами — мої скрипти з типовими іменами (`hero.mjs`, `layers.mjs`, `shots.mjs`, `cnt.mjs`, `q.mjs` тощо) могли перезаписати чужі файли з тими ж іменами.
