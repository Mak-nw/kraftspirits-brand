Рішення замовника (19.10.2026): «в хедері, зліва від кошика треба поставити перемикач мови. Випадайка логікою як на ховері меню, переключає на англійську мову».

## 2. Варіанти архітектури

**A. Статична генерація двох мов на збірці (обрано).** `/` = uk, `/en/…` = en; шаблони з ключами, словники uk/en, `lang`/`hreflang`/canonical/sitemap на збірці.
+ SEO (кожна мова — своя URL-адреса з повним HTML), нуль JS для рендеру, працює на GitHub Pages без сервера, мова лінків зберігається «безкоштовно» (відносні `href`), швидкий LCP.
− розмітка містить ключі, а не текст (правки копірайту — у словниках); довгі англійські рядки треба перевіряти (D17).

**B. Клієнтська підміна тексту (`data-i18n` + JS після завантаження).** Одна сторінка, словник у браузері.
+ найменше змін у розмітці. − мигання українського тексту (CLS), порожній текст для ботів/без JS, англійська не індексується, зайвий JS на кожній сторінці. Відхилено.

**C. Окрема копія сайту (`site_en/`).** + повна свобода. − подвійна підтримка, розбіжність дизайну, порушує «header/footer — єдині partials». Відхилено.

Відхилено також `<html lang>`-перемикання без окремих URL (немає індексації й посилань «поділитись англійською»).

## 3. Як це працює (варіант A)

* **Ключі.** У partials і HTML — `%t.<ключ>%` (як `%contacts.*%`). Словник — плоский об'єкт `{ 'header.menu.home': 'Головна' }` у `src/i18n/uk/<файл>.js` і дзеркально `src/i18n/en/<файл>.js`; файли зібрані в `uk/index.js`, `en/index.js` (`dicts.js` для збірки). Значення — готова розмітка (`<br>`, `<a>`), без символу `"` (він ламає атрибути; використовуй «» “” ’).
* **Українська не змінилась ні на піксель**: значення uk = колишній текст, збірка підставляє їх у ті самі місця (звірено порівнянням dist до/після: різниця лише перемикач і службовий скрипт).
* **`/en/<сторінка>.html`** — однорядкові стаби (`tools/i18n.mjs → writeStubs`, у `.gitignore`, пишуться при кожному старті vite); `vite.config.js` підставляє в стаб вміст кореневого `<сторінка>.html` і рендерить його мовою `en` (`transformIndexHtml`: partials → `%contacts%` → `%t.%` → `localizeHtml`). Build бере стаби входами (`dist/en/*.html`), **dev (vite) працює без змін** (`/en/index.html`).
* **BASE_PATH.** Усі посилання між сторінками — відносні (`about.html` з `/en/` веде в `/en/about.html`), ресурси — через base Vite: `/kraftspirits-brand/en/…` працює. Мова зберігається під час навігації без жодного JS.
* **Перемикач** (`partials/header.html`, `.site-header__lang`): кнопка «UA»/«EN» (`.nav-cell--outline`, як «меню») + список `.site-header__menu--lang` (той самий випадний компонент і `initDropdown` у `src/js/header-menu.js`: hover на пристроях з наведенням, клік/дотик, Enter/Space/Esc/↑↓/Home/End, `aria-expanded`/`aria-haspopup`/`aria-controls`, закриття кліком поза, фокус-кільце). Пункти — прості посилання на ту саму сторінку іншою мовою (`%lang.uk%`/`%lang.en%` розкриває збірка; JS додає поточні `?query#hash`). Активна мова — `aria-current="true"` + стан selected контурної кнопки (існуючі токени).
* **Збереження вибору.** Клік по мові пише `localStorage.ks_lang` (`uk`|`en`; cookie не потрібні: сервера нема). Inline-скрипт у `<head>` кожної української сторінки (до paint) за `ks_lang=en` переспрямовує на `/en/<та сама сторінка>` з `?query#hash`; англійські сторінки нікуди не переспрямовують (петлі нема). Без JS працюють звичайні посилання. Автовизначення мови за `navigator.language` НЕ вмикали (рішення замовника, п. 5).
* **`<html lang>`.** uk: `uk`. en повністю перекладена сторінка: `lang="en" data-locale="en"`. Сторінка-чернетка: `lang="uk" data-locale="en"` + `lang="en"` на `<header>`, `<footer>`, `.age-gate` (перекладені), `<meta name="robots" content="noindex">`, canonical → українська. `runtime.js`: `locale()` читає `data-locale`.
* **hreflang / canonical / sitemap.** Лише коли збірка знає домен: `SITE_URL=https://mak-nw.github.io npm run build` (у workflow додати змінну) → `<link rel="canonical">`, `<link rel="alternate" hreflang="uk|en|x-default">` для пар зі статусом done, `dist/sitemap.xml`. Без `SITE_URL` ці теги не пишуться (hreflang вимагає абсолютних URL).
* **Статус сторінки** — `src/i18n/config.js → PAGE_STATUS`. Нова повністю перекладена сторінка = рядок `'<сторінка>': 'done'` після `npm run qa:i18n` без зауважень.
* **404** і **design-system** мовних версій не мають (`NO_LOCALE_PAGES`); у них перемикач «English» веде на `en/index.html`.
* **Дані** — оверлей: `localizeProduct(p, locale)` (поля name, nameLines, kind, notes, badge, description); відсутнє поле = українське (qa:i18n І4 перевіряє повноту для products/occasions). Для нових наборів — `src/i18n/data/<набір>.en.js` + функція в `localize.js`.
* **Довжина англійського тексту (D17/ширини).** Англійські рядки зазвичай на 10–25 % коротші за українські, але великі caps-заголовки в `.t-hero/.t-h2` можуть переноситись інакше: після перекладу сторінки — `qa:check-ds` (D13/D16/D17), `qa:hscroll`, `qa:cls` на `/en/` (окремі прогони з `--pages en/<сторінка>`). Скорочувати текст, а не стилі.

## 4. Правила

**Додати рядок.** 1) придумати ключ `<область>.<елемент>` (kebab/точки); 2) у розмітці/partial `%t.ключ%` (параметр partial: `text="%t.ключ%"`); 3) значення в `uk/<файл>.js` (точно колишній текст) і `en/<файл>.js`; 4) `npm run qa:i18n`. Рядок для JS — файл `js.js` і `t('js.ключ', { n })`.
**Додати сторінку.** створити `src/i18n/uk/<сторінка>.js` і `en/<сторінка>.js`, додати у `uk/index.js`/`en/index.js` (`files`), замінити тексти ключами, перевірити dist uk без змін (порівняння до/після), виставити `done`.
**Додати мову (напр. pl).** `config.js → LOCALES.pl` (prefix `pl/`), `src/i18n/pl/*`, `DICTS`/`DICT_FILES` у `dicts.js`, `runtime.js`/`localize.js`, пункт у `header.html` (список) — решта (стаби, hreflang, sitemap, перемикач) узагальнена по `LOCALES`; `writeStubs` уже обходить усі мови з префіксом.
**Не перекладаємо:** `YasnoCraft`, `Bazylsprings`, `White Whiskey`, `Barley Spirit`, `Oak Notes`, назви мов у списку («Українська», «English»), e-mail/телефон, slug/URL.

## 5. Статус перекладу

Позначення: **done** — повний; **draft-EN** — англійський текст написано агентом, потрібна редактура (humanizer-en, носій); **draft** — на `/en/` віддається український текст (безпечний варіант: сторінка існує, шапка/футер/ворота англійською, `noindex`, canonical на uk; не редірект — інакше мова «зникала б» при навігації і перемикач не мав би сенсу).

| Сторінка | Статус en | Укр. слів у тілі |
|---|---|---|
| index | **draft-EN** (весь текст, picker, 14 позицій продуктів) — рядки «Place - White Whiskey», слоган «One house, two characters», інтро «YasnoCraft began…» — первинна редактура копірайтером | 0 |
| header, footer, вікові ворота, cart-counter | **draft-EN** (юридичний текст воріт `age.legal` — на перевірку юристу) | 0 |
| about, catalog, product, cart, checkout, account, contacts, feedback, faq, cocktails, barrels, excursions, offer, privacy, cookies, delivery, age-policy, barrels-terms | draft (укр.) | `npm run qa:i18n` друкує актуальні числа (≈ 10 000 слів у HTML + дані) |
| 404, design-system | без en | — |

Юридичні тексти (offer, privacy, cookies, delivery, age-policy, barrels-terms): англійська версія — довідковий драфт; юридична сила — за українським текстом; фраза про це має бути на сторінках (питання замовнику/юристу).

### Чекліст повноти сторінки перед `done`
- [ ] усі видимі тексти, `alt`, `aria-label`, `title`, `placeholder`, `<title>`, `<meta description>` — ключі; JS-рядки — `t()`;
- [ ] дані сторінки мають en (оверлей); ціни через `fmtPrice`; дати — `toLocaleDateString(locale())`;
- [ ] `npm run qa:i18n` — 0; `qa:check-ds` на `/en/<сторінка>` — 0 (D13/D16/D17, особливо переноси заголовків); `qa:hscroll`, `qa:cls`;
- [ ] українська сторінка не змінилась (порівняння dist до/після);
- [ ] `PAGE_STATUS`, таблиця вище, копірайт — humanizer-en.

## 6. Перевірки
`npm run qa:i18n` (ключі uk=en, ключі в розмітці є в словнику, оверлеї даних повні, збірка: на done-сторінках немає кирилиці у тексті й атрибутах, lang/noindex/перемикач, незамінених `%t.%` нема), `npm run qa:links:en` (посилання на `/en/`), `qa:header` (D15: перемикач зліва від «Кошика», `aria-haspopup`, список uk,en), `qa:states`, `qa:hscroll`, `qa:cls`, `qa:check-ds` з `--pages en/index`.
