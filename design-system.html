Стани кнопок

Єдина система токенів станів кнопок — блок «Кнопки: стани» у src/styles/tokens.css. Схема імені: --btn-<варіант>-<властивість>-<стан>; властивість: bg (заливка) · text · border · icon-filter (стрілки слайдера) · opacity (об’єм, каталог-nav); стан: default · hover · focus (:focus-visible) · active (:active, натиснуто) · disabled (:disabled / aria-disabled="true") + selected лише для перемикачів (aria-expanded, aria-pressed / .is-active, .is-open, :checked). Значення — тільки посилання на наявні токени палітри та --color-hover-*; нових кольорів немає.

Прив’язка: варіант (.btn--green, .nav-cell--outline, .arrow-btn, .chip …) виставляє КОНТЕКСТНІ змінні --btn-bg / --btn-text / --btn-border (+ -hover, -focus, -active, -disabled, -selected); база компонента в станах читає лише їх. Тривалості: --btn-transition-duration (0.45s, default ↔ hover), --btn-transition-duration-focus (0.15s, :focus-visible і :active), --btn-transition-duration-base (0.7s, зсув стрілки, zoom мініатюри), крива --btn-transition-ease. Політика переходів: hover/вихід — --btn-transition-duration (0.45s), :focus-visible і :active — --btn-transition-duration-focus (0.15s) для ВСІХ контролів, що змінюють вигляд у фокусі (select, product-thumb, product-volume, check, chip, arrow-btn, nav, логотипи хедера).

Правила станів: focus = hover (клавіатура показує той самий вигляд; відрізняється коротшим переходом і кільцем); active = hover, затемнений на 8% (color-mix(... var(--btn-active-mix) ..., var(--color-black)); для .btn додатково scale(--btn-active-scale = 0.985), перехід 0.15s); disabled = default × --btn-disabled-opacity (нині 0.4 = існуюче значення проєкту), cursor: not-allowed, hover/focus/active без змін, стрілка не зсувається; нативний :disabled додатково pointer-events: none і не фокусується (кільця немає), aria-disabled лишається клікабельним. Іконка кнопки (arrow-up-right) = currentColor = --btn-<варіант>-text-<стан>. Фокус-кільце: --btn-focus-ring-width / -offset (= глобальне :focus-visible, --focus-ring-*); колір — -color-auto (currentColor контексту), -color-on-dark (beige: пілюля хедера), -color-on-light (green: перемикач check).

Область реакції

Правило: клікабельна й ховерабельна вся видима область контролу (фон, рамка, плитка, відступи, іконка), а не лише текст. Фон/рамку/padding має нести сам <button>/<a>; якщо плитка — обгортка (лейбл + кнопка), кнопка отримує клас .hit-area (::after inset:0 від позиціонованої плитки). Не клікабельні: заголовки, підписи. Hover/focus-стан — на всю плитку (:has()). Focus-кільце: глобальне :focus-visible (base.css: --border-hairline, currentColor, --focus-offset); для плитки з .hit-area кільце на ::after кнопки з радіусом плитки (--radius-select), контраст beige/green ≈ 9.4:1 (≥ 3:1). Перевірка: elementFromPoint по сітці всередині видимого прямокутника.

Рух і стани

Плавний, «дорогий» темп: усі переходи й появи повільні та м’які (ease-in-out, без різких стартів). Усе через токени руху (семантичні, вузлів Figma немає) — тривалості не пишемо літералами. Анімуються лише opacity, transform / translate, колір і фон (та висота акордеона) — розкладка в стані спокою не змінюється. Hover — тільки для pointer: fine; фокус клавіатури (:focus-visible) реагує швидко (--duration-focus) і лишається видимим. prefers-reduced-motion: reduce — усе миттєво.
